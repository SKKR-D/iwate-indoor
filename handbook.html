届いていない・開けないと言われたら

メールが届いていない
迷惑メールフォルダを確認してもらう。それでもなければ委員長へ。委員長が管理画面から再送するか、リンクをコピーして個別に送る。
代表者のメールアドレスが変わった
委員長へ。新しいアドレスへ送り直す。
大会トップから再送できないのか
できない。第三者に勝手に再送されるのを防ぐため、再送は委員長だけが行う。
リンクを他チームに転送してよいか
不可。リンクはチーム専用で、開いた人はそのチームとして申し込める。

11/2〜11/3：未開封の確認

管理画面の申込状況には、送信済み・開封（初めて開いた日時）・未開封が出ます。委員長は「未開封」のチームを確認し、届いているかどうかを電話などで確かめます。

11/4〜

申込期間（11/4〜11/19）

監督がスマートフォンかパソコンで申し込みます。申込期間中は、同じリンクから何度でも修正できます。

監督がすること

  1. メールの申込リンクを開く。
  2. 組合せ表記（略称）を入れる（6文字まで。組合せ表・進行表に使う）。
  3. 団体戦：監督（ベンチ入り指導者）と、選手1〜8番を登録名簿から選ぶ。最低4名で、5〜8番は欠員にできる。名簿にない選手は手入力でき、「要確認」として委員長が確かめる。
    個人戦：ペアは連盟が登録済み。ペアごとに監督を入れる。
  4. 申込責任者（氏名・役職・携帯番号・メール）を入れる。
  5. 「個人情報の取扱い」を読み、選手本人・保護者・監督の同意を得ていることにチェックする（チェックがないと送信できない）。
  6. 送信すると、申込責任者に確認メールが届く（申込書PDFを添付、当日受付票（二次元コード）へのリンクつき）。

委員長が見ていること

  • 区分ごとの申込数（申込済 / 出場数）と参加料の合計。
  • チームごとの状態：未申込・申込済、リンクの送信済み・開封・未開封、要確認（名簿にない選手が入っている）。
  • 締切が近づいたら「未申込のチームに督促メール」を送る（未申込の区分だけが対象）。
  • 選手の名簿は団体登録システムから取り込む。登録が追加されたら「名簿を更新」で最新にする。

監督からよく来る問い合わせ

出したい選手が名簿にない
団体登録システムで登録を追加してもらえば、委員長が名簿を更新して選べるようになる。急ぐ場合は手入力で申し込み、委員長が確認する。
申し込んだあとに直したい
締切（11/19 17:00）までは、同じリンクから修正できる。確認メールと申込書PDFも新しい内容で届く。
締切後に選手・監督を変えたい
受付票の「選手・監督の変更申請」から申請する（当日の受付終了 8:00 まで）。「変更申請」の章を参照。
合同ペアの参加料は
連盟が登録したときに決めた支払チームに、まとめて表示される。
参加料の払い方
大会当日の受付で現金（団体戦1チーム10,000円、個人戦1ペア3,000円）。受付が終わると領収書（PDF）が申込責任者にメールで届く。紙の領収書も渡せる。
同意を得られない選手がいる
申し込む前に委員長へ相談してもらう。
受付票をなくした
確認メールのリンクから開ける。当日は受付で「チーム名で探す」こともできる。
11/19〜

締切から組合せ公開まで

申込締切（11/19 17:00）から組合せの公開（11/24）までの流れです。組合せ（案）は申込期間中から作り始めています。組合せは「保存」しても公開されず、委員長が「進行表を作成」を押した時点で公開されます。

11/19 17:00 に自動で変わること

  • 申込フォームは見るだけになる（修正はできない。変更は変更申請へ）。
  • 大会トップが「大会当日の進行表・組合せ・結果」の表示に切り替わる。監督向けの動画、プログラム、選手変更一覧のボタンも出る。
  • 変更申請の受付が始まる。

組合せを作って公開するまで

  1. 組合せ係が、管理画面に組合せパスワードでログインする（「組合せ」タブだけが出る）。
  2. 区分ごとに、枠へチーム（ペア）を選ぶか、Excelの組合せ表を貼り付けて取り込み、組合せを保存。何度でも保存し直せる。この段階では公開されない。申込前のチームも選べ、監督が申し込むと、表示はその略称に自動で変わる（組合せの作り直しは不要）。
  3. 委員長が管理画面で内容を確かめる。
  4. 11/24、委員長が 保存して進行表を作成 を押す。この時点で公開され、組合せ・進行表・プログラムに出る。
  5. 公開後に直す必要が出たときは、試合が始まる前なら委員長が作り直せる（組合せ係は公開後の区分を変更できない）。

組合せの形

個人戦

4ブロック×4ペアの予選リーグ。A・BブロックはAコート、C・DブロックはBコートで、2つのブロックを1試合ずつ交互に行う。試合順は 1-2、3-4、1-3、2-4、2-3、1-4。決勝トーナメント1回戦は A1位－C2位、D2位－B1位、C1位－A2位、B2位－D1位。

団体戦

16チームのトーナメント。Aコートは1〜8番（1-2、3-4、5-6、7-8 → 1〜4の勝者、5〜8の勝者 → 準決勝）、Bコートは9〜16番（同じ形）。決勝は2面展開。

公開すると自動でできるもの

  • 進行表の予定時刻（設定の目安時間から計算。当日は試合の進み具合で自動で計算し直す）。
  • 審判の割当（進行表・本部画面・監督ポータルに表示。決まりは「体制・審判」の章）。
  • 名前入りのスコアシート（予選リーグ・団体戦1回戦）と、白紙の組合せ表。
  • 大会プログラム（結果入り／白紙を切り替えてA4冊子で印刷できる）。
変更

選手・監督の変更申請

申込締切（11/19 17:00）のあとから、その区分の大会当日の受付終了（8:00）まで受け付けます。監督がスマートフォンで申請し、競技委員長が許可すると自動で反映されます。

申請の種類個人戦団体戦
選手変更1ペアにつき1名まで。抜ける選手と同じチームの選手から何人でも（1人ずつ申請）
欠員報告―来られない選手を欠員にする（6名未満は3番手が不戦敗）
監督変更ペアごとチームの監督
締切11/28（土）8:0011/29（日）8:00

流れ

  1. 監督が、受付票（または監督ポータル）の ✏️ 選手・監督の変更申請 から、種類・対象・新しい選手（監督）・理由を入れて申請する。
  2. 本部画面に「📝 変更申請 ○件」と出る（設定すれば委員長にメールも届く）。
  3. 競技委員長が管理画面「選手変更」で 許可して反映 か 却下（理由は必須）を押す。
  4. 許可すると、オーダー画面・スコアシート・進行表・組合せ・プログラムに自動で反映される。
  5. 申込責任者に結果のメールが届き、選手変更一覧（変更前→変更後）に載る。進行表の名前には「変更」の印が付く。

知っておくこと

  • 団体戦で選手を交代すると、すでに提出されたオーダーの名前も新しい選手に置き換わる。欠員にした場合は置き換わらないので、本部がオーダーを訂正する。
  • 登録名簿にない選手への変更は「登録名簿にない選手」と表示される。委員長が登録状況を確かめてから許可する。
  • 8:00 を過ぎると申請できない。やむを得ない場合は委員長の判断で、管理画面から直接入力する。
  • 紙の選手変更届も受け付ける（受付 → 本部 → 委員長が管理画面で入力）。
  • 選手変更一覧は運営ポータルから印刷し、会場に掲示する。監督の変更は氏名だけを載せる（役職・連絡先は載せない）。

本部

本部・進行係

試合のコール・開始・結果入力を行います。本部が入力した結果は、進行表・組合せ表・監督ポータルにすぐ反映されます。

担当ページ運営ポータル →「本部 進行管理」（本部パスワードでログイン）運営ポータルを開く ↗

画面の見方

  • Ａコート・Ｂコートの列に、試合が予定順に並ぶ。各カードに第○試合・回戦・予定時刻・対戦が出る。
  • 枠の色：黄＝呼出中、赤＝試合中、灰＝終了。
  • 予定時刻は、試合が始まると実際の進み具合から自動で再計算される。

1試合の流れ

  1. 前の試合が終わりそうになったら コール。放送で選手と審判（カードの「審判：」）を呼ぶ。
  2. 団体戦 試合開始のあいさつで 📣 オーダー公開。両チームの監督と進行表にオーダーが出る（押し忘れても 開始 で自動公開）。
  3. 試合が始まったら 開始。
  4. コートからスコアシートが届いたら結果を入れる。
    個人戦：結果入力 で勝者とゲーム数（例：4-2）
    団体戦：番手結果 で番手ごとの勝者とゲーム数（例：3-1）
  5. 勝者は自動で次の試合に入る。間違えたら 結果修正、状態を戻すときは 戻す。スコアシートは試合順に保管する。

個人戦（28日）

  • 予選リーグは4ブロック×4ペア。Ａ・ＢブロックはＡコート、Ｃ・ＤブロックはＢコートで、2つのブロックを1試合ずつ交互に行う。1試合7ゲーム。
  • ブロックの試合が全部終わったら、「予選リーグの順位」で1位・2位（Ａ・Ｂブロックは審判をする3位も）を選び ○ブロックの順位を確定。これで決勝トーナメントの対戦が決まる。
  • 決勝トーナメント1回戦：Ａ1位－Ｃ2位、Ｄ2位－Ｂ1位、Ｃ1位－Ａ2位、Ｂ2位－Ｄ1位。

団体戦（29日）

  • 3ダブルス、1対戦5ゲーム。1回戦は3番手まで全部行う。2回戦以降は2勝した時点で決着（残りは打ち切り）。
  • 選手が6名未満のチームは3番手が不戦敗（自動で処理される）。
  • オーダー締切：1回戦は8:40。2回戦以降は前の試合の終了から10分（コート集合は15分）。締切を過ぎても未提出の試合は赤で表示される。
  • 未提出のチームからは紙のオーダー票を受け取り、オーダー から代理入力する。本部は公開の前でも後でも訂正できる。
  • オーダーは本部が公開するまで、相手チームにも観客にも見えない（監督が自分で修正できるのは締切まで。以降の変更は本部が行う）。両チームそろうとカードに「未公開」と出る。
  • 勝ち数が同じとき：得失ゲーム差（自動）→ 得失ポイント差（本部が入力）→ 代表戦（本部が入力）の順で決める。画面の案内に従う。
  • 決勝は既定で2面展開。ほかの試合も 2面展開 で切り替えられる。

記録・掲示係

スコアシートの配布・回収と、組合せ表・進行表の掲示を担当します。

担当ページ運営ポータル →「スコアシート印刷」「組合せ（結果入り）」「組合せ（白紙）」「進行表」「進行表の二次元コード」運営ポータルを開く ↗

スコアシート

  1. 運営ポータルの「スコアシート印刷」を開き、「コート」「範囲」を指定して印刷する（A4縦・1試合1枚）。試合番号・コート・予定時刻・対戦者が印字される。
  2. 予選リーグ・団体戦1回戦は名前入りで前日までに印刷できる。決勝トーナメント・2回戦以降は対戦が決まってから、本部の 🖨 シート で印刷するか、空欄に手書きする。
  3. 予備として「白紙」の枚数を指定して印刷しておく。
  4. 当日は試合順にコートへ渡し、試合が終わったらすぐ回収して本部へ届ける。

組合せ表・進行表の掲示

  • 組合せ（白紙）：結果の入らない記入用。掲示して結果を手書きするときに使う。
  • 組合せ（結果入り）：本部の入力で随時更新。区切りのよいところで印刷して貼り替える。
  • どちらも1区分＝A4縦1枚。「4区分まとめて」で4枚一度に印刷できる。
  • 運営ポータルの「進行表の二次元コード」をA4で印刷して会場入口・観覧席に掲示し、選手・保護者がスマートフォンで予定時刻を確認できるようにする。
  • 選手変更があったら、運営ポータルの「選手変更一覧」（変更前→変更後）を印刷して掲示する。

表彰の準備

決勝が終わると、結果入りの組合せ表の下の欄に優勝〜第3位（個人戦は第1位〜第3位）が入ります。表彰の読み上げはこの欄で確認してください。

コート

コート係（審判員・コート主任）

審判員4人がコート主任としてＡ・Ｂコートに2人ずつ入り、選手審判の確認と進行を行います。終わったらスコアシートをすぐ本部へ戻します。シートが早く戻るほど、次の試合のコールが早くなります。

試合の進め方

  1. 記録・掲示係からスコアシートを受け取る。右上の試合番号・コートが合っているか確認する。
  2. 審判の選手（正審・副審）がそろっているか確認し、シートを渡す。審判は進行表のカードの「審判：」に出る。
  3. 選手名・所属をシートで確認する。団体戦は、本部が印刷したシートなら番手ごとの選手名が入っている。
  4. 試合を行う。個人戦は7ゲーム、団体戦は5ゲーム。
  5. 終了後、勝者サインをもらい、スコアシートをすぐ本部へ届ける。敗者審判の試合では、負けたペア・チームにそのまま次の試合の審判を頼む。

審判員が審判をする試合

  • 個人戦：準決勝・決勝。準決勝はＡ・Ｂ同時なので、4人がＡ・Ｂに2人ずつ入る。
  • 団体戦：決勝。2面展開なので、Ａ・Ｂに2人ずつ入る。
  • それまでは交代で休憩を取り、この試合の前には4人そろっておく。

団体戦の注意

  • 1回戦は3番手まですべて行う。
  • 2回戦以降は、どちらかが2勝した時点で対戦終了（残りの番手は行わない）。
  • 選手6名未満のチームは3番手が不戦敗。シートに「欠員のため不戦敗」と印字される。
  • 2面展開の試合は、2面で番手を並行して行う。進め方は本部の指示に従う。
